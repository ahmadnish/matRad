# LLM Agent for IMRT Radiotherapy Planning

This project implements an LLM-based agent that automates Intensity Modulated Radiation Therapy (IMRT) planning using matRad, MATLAB's open-source radiotherapy treatment planning toolkit. The agent uses LangGraph for workflow orchestration and can iteratively improve treatment plans based on clinical guidelines and objectives.

## Planned Modules

- **agent.py**: Core LangGraph-based agent implementation and workflow
- **matrad_tools.py**: Python wrappers for matRad MATLAB functions
- **guidelines/**: Clinical guidelines and objectives for different treatment sites
- **logger.py**: Comprehensive logging for all agent actions and decisions
- **plan_state.py**: State management for the planning process
- **human_interface.py**: Interface for human-in-the-loop interventions
- **examples/**: Example workflows for different treatment scenarios
